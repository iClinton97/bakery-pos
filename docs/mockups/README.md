# UI mockups

Design mockups for the till app and the live stock page. They are previews made before any code was written, so the layout can be agreed first.

All prices, stock counts and par levels are **sample data**, not real figures.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Cashier: Pies (with a Popular section and colour-coded pie types) |
| `MainHotFood.dc.html` | Cashier: Hot food |
| `MainCakes.dc.html` | Cashier: Cakes |
| `MainSavoury.dc.html` | Cashier: Savoury |
| `MainMisc.dc.html` | Cashier: Miscellaneous (manual price entry) |
| `CardWaiting.dc.html` | Card payment: waiting for the terminal |
| `CardApproved.dc.html` | Card payment: approved |
| `CardDeclined.dc.html` | Card payment: declined |
| `CashPayment.dc.html` | Cash payment and change |
| `EndOfDay.dc.html` | End of day totals, drawer check and closing stock |
| `Products.dc.html` | Manage products, par levels and alert levels |
| `StockLock.dc.html` | PIN screen for the stock page |
| `Stock.dc.html` | Live stock page: pie booth, fridge, other categories and refill list |

The files use a design-canvas format and need its runtime script to render, so they are not meant to be opened directly in a browser. They are kept here as the design reference for the implementation.
